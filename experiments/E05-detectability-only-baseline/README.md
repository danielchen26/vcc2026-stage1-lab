# E05 — 纯可检出性基线 (零生物学)

**状态**: 待做 (阻塞于数据: 需要去年 VCC 2025 的 H1 验证集, 才有真实 R 集可对分)
**前置**: E02 (`d_crit` 逐基因门槛)、`vcclab.detectability.mde`、E04 (官方口径)

## 目的

E02 证明每个基因的检出门槛 `d_crit = 1.96 * sigma_tie / (n1 n2)` 只由官方给的
对照细胞决定, **不含任何生物学**. 那么一个完全不做生物学预测的提交能拿多少分?

这个数字是整个项目的**零点**: 任何 Stage 1 模型如果打不过它, 说明模型学到的
不是生物学, 只是可检出性; 反之, 模型分数减去这个基线才是真实的生物学贡献.
它同时给出「报数 K」的先验 (见 E08).

## 方法 (计划)

1. 用 `vcclab.detectability.mde` 对 gate 内每个基因算最小可检出效应
   (`|lfc|` 使 `|d| = d_crit` 的二分解), 与扰动身份**完全无关**;
2. 按 mde 升序取前 K 个基因 (K ≈ 288, 由 E08 的经验最优点定), 方向用抛硬币
   或用 E06 的共表达符号, 幅度取该基因 mde 的 1.5 倍;
3. 对所有 300 个扰动**报同一个集合** (零生物学: 不区分扰动);
4. 用 Stage 2 解码器 (E03) 构造提交, 用 E04 的官方口径打分.

## 判据

* `de_wilcoxon_sig_jaccard` 的绝对值 —— 这就是基线;
* 与「随机取 K 个 gate 内基因」的对照差多少 (可检出性排序本身值多少分);
* 每个扰动真实 |R| 的分布 (决定 E08 的 K).

## 阻塞

VCC 2026 的目标细胞系没有任何扰动答案, 无法在本季数据上算 jaccard. 需要
去年 (VCC 2025) H1 验证集的真实扰动矩阵作为代理: 同样的打分器口径, 有真答案.
拿到后本实验可在 1 小时内跑完.
