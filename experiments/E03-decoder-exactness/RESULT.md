两点必须说明:

* **耗时不同** (加载 84.9 s vs 12.8 s, de_table 10.49 s vs 3.98 s): 复跑时
  机器上另有两个并发 agent 在跑同样规模的作业, CPU 与 I/O 争用. 原始记录的
  12.8 s / 3.98 s 才是干净进程下的数字; 因此 README 的「60 min 单核 / 6 min
  十核」外推仍以干净进程为准 (复跑那行 157 min 是争用下的悲观值).
* **`lfc 中位绝对误差` / `padj 中位` / `null padj 最小` 与「另一次」记录不同**
  (0.01543 vs 0.00061, 3.05e-12 vs 4.27e-10, 0.133 vs 1.000): 那三个数字来自
  2026-08-27 **首次**实验, 意图集与 lfc 抽样都不一样 (不是本 `run.py` 的
  seed 42 / seed 1). 两者都满足契约 (方向 100%, 假阳性 0, lfc 误差 << 抽样
  幅度 0.4–2.2), 只是量级随意图分布浮动. `run.py` 固定了自己那一套种子,
  以后这三个数字就以本文件的复跑值为基准.
