# E02 — 弥散度旋钮: 显著性与方向的解耦

**状态**: 已完成, 12/12 判定复现
**耗时**: ~15 s (几乎全是 ControlRef 加载; 本身无 RNG, 完全确定)

## 目的

E01 证明打分器对每个基因只读两个标量: 均值 (给 `log2_fold_change`) 与平均中位秩
`psi_bar` (给 p 值). 这里要定量回答: **这两个标量能不能独立操纵?**

如果能, 那么「哪些基因被判显著」与「预测的变化方向/幅度」是两个可以分开设计的
自由度 —— 这正是 Stage 1 / Stage 2 解耦的理论依据, 也是理解官方 6 个指标
互相冲突的钥匙.

## 方法

取一个真实基因 (context_A 的 **SELENOT**, 对照均值 62.54 CPM,
18,400 个对照细胞里有 5,885 个检不到它), 把 400 个细胞的**一阶矩锁死**在
`lfc = +0.322` 对应的 78.18 CPM 上, 只改组内分布形状:

```
非零细胞数  k = round(n / (1 + t))          n = 400
非零值      s = mu * n / k                  => 均值恒等于 mu, 与 t 无关
```

两点分布 `(0 概率 1-f, s 概率 f)`, `f = k/n = 1/(1+t)`, 其组内方差比
`CV^2 = (1-f)/f = t` —— 所以 **t 就是弥散度旋钮**, 单调地把「同一个均值」
从「每个细胞都中等表达」推到「少数细胞高表达、其余为零」.

p 值按 `vcc_local.ControlRef.de_table` 的口径算, 含并列校正:

```
sigma_tie = sqrt(n1 n2 / 12 * ((N+1) - sum_t (t^3 - t) / (N (N-1))))    N = n1 + n2
U - n1 n2 / 2 = n1 n2 * d,   d = psi_bar / n2 - 0.5
```

## 实测结果

见 `RESULT.md`. 关键三点:

1. `t` 从 0 走到 1.30, 均值一动不动 (78.18 CPM, lfc=+0.322), 而 p 从
   **2.8e-29 走到 0.77** —— 同一个预测既可以「必显著」也可以「不显著」.
2. `t = 1.30` 是这个基因的零点 (`d = +0.0043`, 落在 `d_crit = 0.0282` 之内).
3. `t` 继续到 3.00, 均值**仍然向上**, 但 `d = -0.1312` 变成负的, p 回到 5.2e-20
   —— 检验说「显著下调」, 而 `log2_fold_change` 说「上调 0.32」.
   **检验读秩, lfc 读均值, 两者可以指相反方向.**

## 结论

1. 显著性 (`psi_bar`) 与方向/幅度 (均值) 在 400 个细胞的自由度里**完全解耦**.
   Stage 2 因此可以先按 Stage 1 的意图定 lfc, 再单独把 `psi_bar` 推过 / 拉回
   显著门槛 —— 这就是 `ControlRef.design` 里那个对非零比例做二分的循环
   (E03 验证它能做到 100% 召回 + 100% 精确).
2. `d_crit = 1.96 * sigma_tie / (n1 n2)` 是逐基因的检出门槛, 只由官方给的对照
   细胞决定, **不含任何生物学**. 这直接派生出 E05 (纯可检出性基线) 与
   `vcclab.detectability.mde`.
3. 并列校正不是细节: 这个基因 `sigma_tie = 105,724` vs 未校正 `107,384`
   (差 1.5%), 恰好在 `t = 1.05` (p = 0.015) 这类临界行上决定判定翻不翻.
