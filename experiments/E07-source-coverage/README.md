# E07 — 源数据覆盖率 (决定整条路线)

**状态**: 待做 (阻塞于数据下载: Replogle 2022 K562 全基因组 CRISPRi)
**前置**: `pert_counts.csv` 的 300 个靶基因

## 目的

一个**先于建模**的问题: 300 个待预测的扰动里, 有多少个在已发表的全基因组
CRISPRi 数据 (Replogle 2022 K562 essential + genome-wide) 里已经有实测反应?

这个比例直接决定路线, 二者的工程量差一个数量级:

* 覆盖率高 (比如 > 80%) -> 问题是**跨细胞系迁移已知响应**: 拿 K562 的 delta,
  按目标 context 的对照表达重标定, 再送进 Stage 2. 不需要学习扰动 -> 表型的映射.
* 覆盖率低 -> 问题是**预测未知扰动**: 必须靠靶基因的功能表征 (通路、复合体、
  共表达邻域) 泛化, 即 E06 那条路.

## 方法 (计划)

1. 取 Replogle 2022 的扰动列表 (K562 essential ~2,057 个 + genome-wide ~9,867 个),
   与 300 个靶基因求交; 基因名要过一遍别名表 (HGNC) 再对, 否则会低估;
2. 对交集内的扰动, 检查其显著响应基因是否落在我们的 gate 内 (三个 context 的
   gate 各 9,929 / 9,626 / 10,124), 算「可用响应基因」的覆盖率;
3. 对交集外的扰动, 统计它们在 STRING / CORUM / Reactome 里与交集内扰动的邻接度
   —— 决定「借邻居的答案」这一招的可行上限.

## 判据

* 300 中的命中数 (以及别名匹配前后的差);
* 命中扰动的响应基因有多少落进 gate;
* 未命中扰动里有多少能找到一个高置信功能邻居.
