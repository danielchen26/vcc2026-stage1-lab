# E06 — 共表达能不能定符号

**状态**: 待做 (不阻塞, 数据齐: 只需三个 context 的对照细胞)
**前置**: E04 (`direction_reach` 是阈值型指标, 纯度 < 0.9 拿 0 分)

## 目的

E04 显示 `direction_fidelity` 在方向随机时约 0.5, 而 `direction_reach` 在纯度
达不到 0.9 时**直接给 0**. 所以 Stage 1 的方向预测要么做到高纯度, 要么不值得报.

CRISPRi 敲低靶基因 g 会让与 g 正相关的基因跟着下降、负相关的上升, 即

```
sign(delta_h) ≈ -sign(corr(g, h))
```

关键是: **`corr` 只需要目标细胞系自己的 18,400 个对照细胞**就能算 —— 零迁移风险,
不需要任何扰动答案. 本实验要量出这个符号规则的纯度天花板.

## 方法 (计划)

1. 在每个 context 的对照 CPM 上算 gate 内基因两两相关 (9,929² 的一半,
   float32 约 200 MB; 或只算 300 个靶基因对 gate 的 300 × 9,929 条);
   注意成分数据: 先 log1p, 再考虑用 Spearman 或 CLR 变换消掉库大小伪相关;
2. 用去年 H1 或 Replogle K562 (E07) 的真实 delta 做标签, 算符号一致率
   (逐扰动纯度), 并按 |corr| 分层看纯度 —— 找到「报还是不报」的 |corr| 阈值;
3. 与三个 null 对照比: 抛硬币 (0.5)、全报下调、按对照均值排序.

## 判据

* 分层纯度曲线: 在多大的 |corr| 阈值上纯度 ≥ 0.9 (`direction_reach` 的门槛),
  以及这时还剩多少个基因可报;
* 纯度是否跨 context 稳定 (决定能不能 zero-shot 迁移);
* 靶基因自身 (敲低必然下调) 是否被规则正确覆盖 —— 这是唯一的免费正确答案.
