# E16 结果 — leverage 在**排序统计量**，不在跨系迁移

**日期**：2026-08-30 · **耗时** 503 s · **n** = 25 个扰动（细胞数 ≥ 800）
**设置**：每扰动对半劈开，只用半 A 构造排序，靶 = 半 B 独立算出的官方 $R_p$，
统一 $K = \lvert R_p(B)\rvert$ 预言机规模（隔离排序质量）

## 判定

> ### 官方 $p_{\text{adj}}$ 排序给 $h = 0.551$，比裸 $\lvert\beta\rvert$ 的 0.232 高 **2.37×**，**25/25 全胜**
> ### 而 MDE 归一化**毫无价值**（p = 0.52）

| 排序统计量 | $h$ 中位 | IQR | vs ① |
|---|---|---|---|
| ① $\lvert\beta\rvert$（裸对数倍数变化） | 0.232 | [0.151, 0.397] | 1.00× |
| ② $\lvert\beta\rvert/\mathrm{MDE}$ | 0.212 | [0.167, 0.377] | 0.91× |
| **③ 官方 $p_{\text{adj}}$（同系上限）** | **0.551** | [0.458, 0.600] | **2.37×** |
| ④ $1/\mathrm{MDE}$（零生物学地板） | 0.023 | [0.000, 0.151] | 0.10× |

**配对 Wilcoxon**：② vs ① 胜 11/25、**p = 0.523（无差异）**；
③ vs ① 胜 **25/25**、p < 1e-5；③ vs ② 胜 **25/25**、p < 1e-5。

③ 的 0.551 与 [E11](../E11-replicate-anchor/) 独立测得的 $h_{\text{replicate}} = 0.550$
完全吻合 ✓ ——两条互不依赖的路径给出同一个数，上限可信。

## 缺口分解

| 缺口 | 幅度 |
|---|---|
| 统计量损失（① → ③） | **58%** |
| 跨系损失（[E14](../E14-crossline-h/) 的 0.145 vs ③ 的 0.551） | 74% |
| 其中跨系相对同系 $\lvert\beta\rvert$ 排序（0.145 / 0.232） | 只损失 **37%** |

**跨系迁移不是瓶颈。** 真正的鸿沟是：同一个细胞系、同样 400 个细胞，
只因为换了排序统计量就差 2.37 倍。

## 为什么 MDE 归一化没用（机制）

`MDE` 的定义是「把对照分布**整体乘** $2^{lfc}$，求刚好达显著的最小 $\lvert lfc\rvert$」
—— 它假设扰动是**均匀乘性位移**。

但官方判据是 $\lvert\bar\psi - 0.5\rvert$ 超阈，其中 $\bar\psi$ 是我们 400 个细胞
在该基因**对照 ECDF 上的平均分位位置**。$\bar\psi$ 对**分布形状的改变**极其敏感 ——
尤其是零计数细胞比例的变化，而那几乎不动均值 CPM。

$$\text{②/③} = 38.4\% \;\Longrightarrow\; \text{秩位移里有 } \lvert\beta\rvert \text{ 与 MDE }
\textbf{都抓不到}\text{ 的信息}$$

## 由此得到的算法方向

**预测 $\bar\psi_g$（平均分位位置），不要预测 $\beta_g$。** 理由：

1. 它**就是**官方统计量（单调等价）→ 翻译过程不丢信息
2. 有界 $[0,1]$、无量纲、跨基因可比 → 统计性质更好
3. 自动吸收逐基因的分布形状 → 不需要 MDE 归一化（E16 已证明归一化没用）
4. E16 实测：在**同等信息量**下值 **2.37×**

当前 [E14](../E14-crossline-h/) 的跨系 $h = 0.145$ 是同系上限 ③ 的 26.3%，
追平线是 23%。**只要把 2.37 倍里拿回三分之一，就能从 1.15× 追平线走到约 2×。**
