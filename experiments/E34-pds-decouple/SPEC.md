单调、有平台、无尖峰 ⇒ 取 **1.0**。

### 0b. $k_{\text{off}}$：`k=500` 的尖峰先被假定是伪影 —— **两项检验都推翻了这个假定**

| $k_{\text{off}}$（scale 1.0） | local pds | Δ vs A | 量子数（1/56） |
|---|---|---|---|
| 300 | 0.7679 | +0.0357 | 2 |
| **500** | **0.8750** | **+0.1429** | **8** |
| 1000 | 0.8036 | +0.0714 | 4 |
| 2000 | 0.7857 | +0.0536 | 3 |
| 3000 | 0.7857 | +0.0536 | 3 |

**三条理由说明不能直接取 500：**

1. **孤立尖峰。** 两侧（300 → 0.7679、1000 → 0.8036）都明显更低，没有邻域支撑。
   真优化点应当有平台（对比 §0a 的 $\lambda$ 曲线就有）。
2. **在评估集上选参数。** 这 8 个扰动既是调 $k$ 的集合，也是算 pds 的集合。
   而 `pds` 是**组内排名**（`rank_denominator="n-1"`、`exclusion_scope="panel"`，
   `run.py:58-68`）—— 它的值依赖 panel 组成（[T8](../../docs/06-traps.md#t8)），
   所以「在这个 panel 上最好的 $k$」与「可迁移的 $k$」是两回事。
   迭代纪律写得很清楚：只提取可迁移的超参数，**不要记忆某个集合**。
3. **增益集中在最难的两个扰动上。** $k$=500 相对 $k$=1000 的全部增益来自
   TCF7L2（0.57 → 1.00）与 GNG12（0.29 → 0.57）—— 恰好是基线 pds 最低的两个
   （0.43 / 0.14），也是源侧显著基因数最少的两个（`n_src` = 1 与 5）。
   增益**集中**而非分散，按 [F33](../../docs/02-findings.md#f33) §3b 用过的同一判据，
   这是噪声/过拟合的形状，不是机制的形状。

### 0c. $k_{\text{off}}$ 的选择规则（`stability.py`，执行前定死）

两个检验，**都要过**：

- **密网格** $k \in \{300,350,400,450,500,550,600,700,800,1000\}$：
  峰值必须有邻域支撑 —— 峰值与其相邻两点的差 ≤ 1 个量子（0.0179）。
- **留一法** 8 次（剔 1 个扰动，7 扰动 panel，量子 1/42）：
  只在**同一 LOO panel 内**横向比 $k$，绝不跨 panel 比绝对值。

| 否则 | $k_{\text{off}} = \mathbf{1000}$（有 2000/3000 的平台支撑），预测按 **+4 量子** |

§4 的中心预测按**保守分支（k=1000，+4 量子）**写。若 500 过了检验，
预测上调为 pds raw 0.8214 → 0.8750 一档，但 **§5 的判定门不随之上移**。

## 1. 假设（一句话，可证伪）

> 把去面板均值的 lfc 只铺在**召集集之外**，能拿到 `pds_cosine` 的全部收益，
> 而 `de_wilcoxon_direction_reach_raw` 与 `de_wilcoxon_sig_jaccard` 结构上不受影响。

### 为什么它可能成立（机制，不是希望）

`design_cells`（`src/vcclab/decoder.py:119-128`）把一阶矩和显著性**分成两条通道**：

```python
lf = np.zeros(ref.n_genes)
if lfc_all is not None:
    ...
    la = la - float(w @ la)      # 第 126 行：质量加权居中，使 renorm ~ 1
    lf[ref.gidx] = la            # 第 127 行：一阶矩给全部 gate 内基因
lf[ref.gidx[r_set]] = lfc        # 第 128 行：召集集上的值**覆盖** lfc_all
```

- 第 128 行保证召集集那 288 个 lfc **逐位等于 V8**；
- 显著性（两点分布 $\psi$）只加在 `r_set` 上（`decoder.py:140-156` 的循环只遍历 `r_set`），
  **`lfc_all` 不产生任何新的显著基因**。

`reach` 测的是我们自己 $\lvert\text{lfc}\rvert$ 排序的方向纯净前缀深度 $k^\ast/N_{\text{conf}}$，
`jac` 测的是召集集与 real 显著集的交并比 —— 两者都由 `r_set` 决定。`r_set` 不动 ⇒ 两者不动。

### 已测的支撑证据

本地闭式探针（`out/decouple.log`，2026-09-22）：

| 设计 | local pds | Δ vs A |
|---|---|---|
| A 召集 288 原值（= V8 现状） | 0.7321 | — |
| C 全基因去面板均值 | 0.7500 | +0.0179 |
| F `top1000` 单独（无去均值） | 0.7143 | **−0.0178** |
| G `top1000` + 去面板均值（= V2 那条路） | 0.7857 | +0.0536 |
| H 召集 288 + 其余**全部**去均值 | 0.7500 | +0.0179 |
| **I 召集 288 + 其余 `top1000` 去均值** | **0.8036** | **+0.0714** |
| J 同 I 但 ×0.3 压幅 | 0.7143 | −0.0179 |

三条读数：

1. **`top1000` 单独是亏的**（F < A）。pds 的收益全部来自去面板均值，不是 top-K。
2. **I > G**：解耦不但可行，还比 V2 那条「连召集集一起改写」的路更好。
3. **J 亏**：新通道对幅度敏感，所以 $\lambda_{\text{off}}$ 必须扫，不能直接沿用 0.7
   （[T10](../../docs/06-traps.md#t10) 的教训：不许外推）。

独立支撑 —— [T11](../../docs/06-traps.md#t11) 实测 `pds_cosine` raw **对 $\lambda$ 完全不变**
（V5 = V6 = 0.7143，V7 = V8 = 0.7500），只随 $K$ 变。所以 `lfc_all` 既不是 $\lambda$
也不是 $K$，**它是一个此前不存在的第三个 pds 旋钮**。

逐字不动的量：$\lambda = 0.7$、$K = 288$ 扁平、排序统计量 $\lvert\beta\rvert$、
`N_PERT = 8`、`seed = 0`、`quantizer = "hamilton"`、`force_mean = True`、

生成方式：由 `experiments/E28-pds/build_v8.py` **逐字复制 + 恰好一次 `str.replace`**，
替换后断言旧串消失、新串出现、且 `len(new) - len(old)` 等于替换串的长度差
（照 `E31-iid/gen_v9.py` 的手法）。记账性替换（输出目录、提交标签）各自单独断言。

## 5. 判定与停止条件（build 前定，事后不许挪门）

pds 的量子是 0.0179，所以「赢」必须大于一个量子，否则不可区分于秩的抖动。

| 结果 | 判定 | 动作 |
|---|---|---|
| `avg_lo` ≥ **0.1394**（= 0.1215 + 0.0179） | **GO** | V13 取代 V8 成为当前最优；写 F34；把 $\lambda_{\text{off}}$/$k_{\text{off}}$ 记进 05-stage1-design |
| 0.1215 < `avg_lo` < 0.1394 | **不确定** | 不改基线。只记录，不据此做第二步决策（一个量子内的差不构成证据） |
| `avg_lo` ≤ 0.1215 | **NO-GO** | P1 关闭。写 F34 记录「本地闭式探针不迁移到官方打分器」这条方法学结论 |

**独立停止条件（任一触发即中止并回头改机制论证，不许改门槛）：**

1. `pds_cosine` raw ≤ 0.7500 —— 本地探针不迁移，整条路的前提就没了。
2. `sig_jaccard` 或 `direction_reach` raw 发生**任何**变化 —— §1 说它们结构上不动；
   一动就说明 `lfc_all` 影响了显著性通道，`decoder.py` 的两通道分离是假的。
   这比 pds 输掉严重得多，**优先级高于本实验本身**。
3. 官方打分器新增任何告警（V6/V7/V8 已有 i.i.d. 那一条；新增的要单独查）。
4. 召集集 lfc 的逐位断言失败 —— 说明不是单旋钮。
