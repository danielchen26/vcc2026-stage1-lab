# E01 — Wilcoxon 秩和的闭式约化 (psi 恒等)

**状态**: 已完成, 3/3 逐位相等 (+ 真实数据 5/5 闭环)
**耗时**: 合成部分 ~10 s; 加 `--real` 约 +60 s (一次 ControlRef 加载)

## 目的

官方打分器 `cell-eval2` 0.16.0 (preset `vcc2026`) 的六个指标里, 四个走
Wilcoxon 秩和检验. 如果 U 统计量对提交的 400 个细胞有闭式, 那么:

1. 我们可以在不调用官方打分器的前提下, 精确知道每个基因会不会被判显著;
2. 因为对照组在整场比赛**固定不变**, 那张「秩表」可以预排序、离线复用;
3. Stage 1 (预测哪些基因响应) 与 Stage 2 (构造 400 个整数细胞) 可以彻底解耦.

本实验就是检验这个闭式对不对 —— 不是「近似相等」, 是**逐位相等**.

## 方法

断言:

```
psi_g(v) = #{c : x_cg < v} + 0.5 * #{c : x_cg = v}
U_g      = sum_{i=1..400} psi_g(v_i)
```

其中 `x_cg` 是 18,400 个对照细胞在基因 g 上的 CPM, `v_i` 是提交的第 i 个细胞.
`psi` 的实现方式与 `vcc_local.ControlRef.psi` 完全一致: 把对照列拆成
「零的个数 + 排好序的非零值」, 用两次 `searchsorted` (`left`/`right`) 拿到
小于与等于的计数, 并对 `v == 0` 走 `0.5 * nzero` 的快路径 (稀疏矩阵里零不显式存储).

对照物是 `scipy.stats.mannwhitneyu(treat, ctrl, method="asymptotic").statistic`
—— 官方 scanpy 后端用的就是这个渐近口径.

三个情形 (合成, `default_rng(0)`, 负二项 r=2):

| 情形 | 处理组分布 | 为什么要测 |
| --- | --- | --- |
| null draw | NB(mean=40) = 对照同分布 | 常规情形 |
| shifted | NB(mean=60) | 有真实位移时 |
| degenerate | 400 个细胞全等于 44 | **点质量**: 400 个值全部并列, 并列校正项最大, 最容易暴露实现错误 |

`--real` 追加一个真实数据闭环: 在 context_A 上随机抽 5 个 gate 内基因,
用真实对照 CPM 列 (含 4k–10k 个精确零) 与自举放大 1.4 倍的 400 个细胞,
再跟 scipy 对一次 —— 覆盖合成数据碰不到的稀疏 / 并列结构.

## 实测结果

见 `RESULT.md`. 三个情形 U 全部与 scipy **逐位相等** (`==`, 不是 `allclose`),
含 400 细胞全并列的退化情形; 真实数据 5/5 相等.

## 结论

1. 闭式成立. 打分器对每个基因只经过两个标量: (a) 400 个细胞的均值 (决定
   `log2_fold_change`), (b) 平均中位秩 `psi_bar` (决定 p 值). 六个指标全部
   是这两个标量的函数.
2. 因此可以预排序对照列, 每个基因只做 400 次 `searchsorted` -> E04 实测比
   官方 CPU 后端快 38.8x.
3. 推论 (由 E02 定量): 均值和秩可以**独立操纵**, 于是 Stage 2 能把任意
   「显著集 + 方向」意图无损写进整数计数矩阵 (E03 验证).
