# E08 — 报数 K 的经验最优点

**状态**: 待做 (阻塞于真实 R 集: 同 E05, 需要去年 H1 或 E07 的 Replogle 标签)
**前置**: E03 (解码器能精确报出任意 K)、E05 (排序打分)

## 目的

E03 证明我们可以**精确**报出任意大小的显著集 K —— 于是 K 变成一个纯粹的
决策变量, 不再受构造能力限制. 而 jaccard 是

```
jac = |R̂ ∩ R| / |R̂ ∪ R|
```

K 太小 -> 分子上不去; K 太大 -> 分母被自己撑爆. 直觉上最优 K 应该在真实
`nReal = |R|` 附近, 但这只在排序**完美**时成立: 排序有噪声时, 最优 K 会往
小的方向偏 (多报的都是假阳性, 只吃分母).

本实验要量出这个偏移, 因为它是提交策略里唯一一个不用建模就能调对的旋钮.

## 方法 (计划)

1. 固定一个排序器 (E05 的可检出性排序, 之后换成 Stage 1 的真排序);
2. 对 K 从 50 扫到 1,000, 逐 K 算解析 jaccard (不需要构造提交:
   E03 已证明报什么就实现什么, 所以 `R̂` = 排序前 K 个);
3. 对每个扰动分别扫, 看最优 K 与该扰动 `nReal` 的比值分布;
4. 用排序器的 AUC / precision@K 做参数, 拟合「最优 K / nReal」对排序质量的
   依赖曲线 —— 得到一条可外推到未知排序质量的规则.

## 判据

* `argmax_K jac` 与 `nReal` 的比值 (点估计 + 跨扰动分布);
* 在最优点附近 jac 的平坦程度 (决定 K 估错的代价, 以及要不要逐扰动定 K);
* 一个可直接用于提交的 K 选择规则 (常数? nReal 的比例? 由 mde 分布定?).

## 备注

`nReal` 本身也要预测. 若 E07 覆盖率高, 可用 Replogle 的 `nReal` 做代理;
否则用去年 H1 的 `nReal` 分布做先验 (它与靶基因的表达量、必需性相关).
